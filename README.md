# FH6 涂装查看器 (FH6 Livery Viewer)

**[English](README_en.md) | 中文**

在游戏外浏览《极限竞速：地平线 6》本地存档中的涂装：缩略图平铺、显示**具体车型**与**作者**、可缩放的大图预览。解决游戏内涂装管理界面看不到车型、无法预览纹饰的问题。

**只读工具 —— 不会修改任何存档文件。**

## 功能特性

- 🖼️ **缩略图平铺**：直接读取存档自带的 `bigThumb` 预览图，卡片墙展示全部涂装
- 🏎️ **显示具体车型**：内置 660 辆车的 ID 对照表（与游戏数据逐条对齐；v1.3.0 已按游戏 6.420.696.0 复核——无新车，按游戏 ModelShort 年份后缀修正 9 处年份），不再对着一串数字猜车
- 📍 **游戏内位置**：每个涂装标注它在游戏「我的涂装」里的行列位置（缩略图角标 + 详情），可按游戏内顺序排列，照着就能在游戏里翻到
- 🎯 **自动定位**：详情面板直接给出从 1行1列 出发的最短方向键路径（利用首尾环绕），「自动定位到游戏」按钮一键切到游戏并发送方向键，精准跳到目标涂装
- 📌 **窗口置顶**：一键把窗口浮在游戏上方，玩着游戏随时查涂装、按定位
- 🔃 **自动刷新**：顶栏开关默认开，轮询当前存档目录（3s 轮询 + 2s 防抖）；游戏里新下载/删除涂装后无需手动点「刷新」——新涂装以插入方式进入卡片墙，选中项与滚动位置保持不变，状态栏提示「检测到存档更新: +N 新增 / -M 删除, 已刷新」；可随时关闭，手动「刷新」按钮保留原语义
- 🔄 **重复涂装检测**：感知哈希两两配对推断重复涂装，无预制模式——判定条件由用户在筛选栏右侧「重复检测参数」按钮弹出的对话框里自由组合：车型相同/不同、作者相同/不同、图片感知哈希距离阈值（或任一方无预览图文件）、名称相似度阈值、创建时间/下载时间相同/不同，六个维度任意叠加，同时满足所选条件的两条涂装判为重复并按传递关系合并成组；对话框内置 4 个常用「模板」一键填表（同车微调、跨车型移植、同名异版、多次下载），再次打开自动回填上次应用的值，与某模板完全一致时自动选中该模板名。出厂默认 = 同车型且图片距离 ≤6；确定后即用已缓存特征毫秒级重算（改动仅本次运行有效，不落盘）；分析按需触发，不筛选则零开销
- 🗂️ **重复涂装分组展示**：打开「仅显示重复涂装」后，卡片墙按重复组聚拢并在每组前显示通栏组标题行（第 N 组 · 成员数）；排序方式同时作用于组间和组内
- 🟢 **已喷涂检测**：游戏运行时只读扫描游戏进程内存（不写、不 hook、不附加调试器），标记哪些涂装正喷在车上。顶栏「⚠ 检测喷涂状态」按钮一键检测：弹原理与风险确认框，确认后开始扫描并自动用喷漆角标标出已上车涂装（琥珀橙 `#E69F00` 喷漆罐角标贴在卡片左上角，色盲友好；检测结果当次会话内常显，无需任何开关，切换存档后自然消失），完成提示「已标记喷涂」（游戏未运行则提示）；需游戏运行中才可用。另有「仅显示已喷涂」「仅显示未喷涂」两个筛选开关（互斥），加详情面板喷涂状态与状态栏计数；两个筛选开关在本会话未扫描过时打开也会弹同款确认框，取消则开关回退无效，已扫描过后开关直接生效不再弹
- ⚡ **性能优化**：卡片墙单 Canvas 虚拟绘制（v1.4.0 重构），滚动流畅不闪屏；缩略图线程池后台解码（180 张约 0.36s，不卡 UI）、重复检测并行化（实测 3.74x）、内存全量扫描并行提速（稳定约 3.9s）
- 🔍 **车型表内存校对**（v1.3.1）：新增 `gamemem.read_car_strings()`，运行时从游戏内存读取 `Data_Car` 的 DisplayName / ModelShort 串表，重新生成并校对 `cars.json`，修正多处车型名；同时优化缩略图解码失败时的保留旧图与退避重试
- 🌐 **多语言界面**（v1.6.0）：简体中文（默认）、English、日本語、한국어、繁體中文 五种语言，按下载包内 exe 文件名自动选择（如 `FH6LiveryViewer_en.exe` 即英文界面），无需任何设置
- 🔤 **数据字体 Consolas**（v1.6.0）：卡片与详情里的用户数据文本（涂装名/车型/作者等）用 Consolas 显示，`I` 与 `l` 一眼可辨（微软雅黑里两者都是光杆竖线）；中文/日文/韩文字符经 Windows 字体链接自动回退，无缺字

- 🏭 **车厂筛选**：按车厂快速过滤（保时捷、法拉利……）
- 🔍 **可缩放预览**：卡片右键菜单「查看缩略图」（或详情面板「查看大图」/ 双击右侧预览图）打开大图，滚轮缩放（5%–1200%）、拖动平移、原始尺寸/适应窗口
- 📅 **下载日期排序**：按涂装写入存档的时刻排序（新→旧/旧→新），也可按名称/车型/作者/车厂/游戏内顺序排序；可另选「次选」条件作为第二关键字（默认「无」=不启用），分组展示下同时作用于组间与组内
- 🗂️ **分组显示**：可按车厂、作者或车型为卡片墙分组（通栏标题行标明组名与数量，组间顺序跟随当前排序，取不到值的归入『其他』并置底；按车型分组时组名为车型显示名，未识别车型的自成一组）；选中任一维度时会自动把主选排序切换为对应模式，组间按该维度顺序排列
- 🔎 **搜索**：按涂装名/作者/车型过滤；双搜索框可同时输入两个关键字做与组合（两框中间的「+」即此意），只填第一个框时等同单关键字搜索
- ⚡ **右键快筛**：卡片右键菜单「只显示该车型」「只显示该作者」快速聚焦；激活时筛选按钮文案出现「快筛」段，同一菜单顶部「清除快筛」即可复原（切存档自动清空）
- 📋 **原生复制**：详情文本可选中复制（Ctrl+C / 右键菜单），卡片右键菜单复制位置/名称/车型/作者
- 💾 **一键备份**：把整个存档目录打成 zip（只读操作）
- 🖥️ **双版本存档支持**：Steam 版（userdata）与商店/Xbox 版（`XboxGames\GameSave\pgs`）自动识别

## 环境要求

- Windows 10/11
- Python 3.10+
- [Pillow](https://pypi.org/project/Pillow/)（`pip install pillow`）——用于解码 FH6 存档的 WebP 预览图；不装也能运行，但涂装缩略图无法显示

## 下载

[Releases](https://github.com/Hx-zh/fh6-livery-viewer/releases) 提供五个 zip，区别只在界面语言（程序按包内 exe 文件名自动选择语言）：

| zip（`vX.Y.Z` 为版本号；语言标签为 BCP 47） | 界面语言 |
|---|---|
| `FH6LiveryViewer_vX.Y.Z_win64_zh-CN.zip` | 简体中文 |
| `FH6LiveryViewer_vX.Y.Z_win64_zh-TW.zip` | 繁體中文 |
| `FH6LiveryViewer_vX.Y.Z_win64_en.zip` | English |
| `FH6LiveryViewer_vX.Y.Z_win64_ja.zip` | 日本語 |
| `FH6LiveryViewer_vX.Y.Z_win64_ko.zip` | 한국어 |

## 快速开始

```bash
pip install pillow
python app.py
```

启动后自动定位本机 FH6 存档（Steam 读注册表，商店版扫描 `XboxGames\GameSave\pgs`），也可以用「手动选择目录…」指定 `remote` 或 `ContainersRoot` 目录。

## 打包发布

```bash
python -m PyInstaller FH6LiveryViewer.spec
```

产出为单文件 `dist\FH6LiveryViewer.exe`，`cars.json` 已内嵌（运行时只读，不释放到用户目录）。构建一次后，把 exe 复制改名为 `FH6LiveryViewer_zh-CN.exe` / `_zh-TW.exe` / `_en.exe` / `_ja.exe` / `_ko.exe`（BCP 47 语言标签）即得到对应语言的界面（程序按自身文件名选语言；开发时可用环境变量 `FH6_LANG=en` 等覆盖）。


## 使用说明

| 操作 | 说明 |
|---|---|
| 单击卡片 | 选中，右侧显示大图与元数据（名称/车型/作者/游戏内位置/按键路径/日期/层数/大小/重复组） |
| 双击卡片 | 自动定位到游戏内该涂装（等同详情面板「自动定位到游戏」按钮） |
| 右键卡片 | 弹出菜单：查看缩略图 / 定位到涂装位置 / 只显示该车型、只显示该作者（右键快筛，激活时菜单顶部「清除快筛」复原）/ 复制游戏内位置、名称、车型、作者 |
| Ctrl+C | 焦点在详情框时复制选中文本；否则复制选中涂装的游戏内位置 |
| 「涂装筛选」 | 全部为独立开关，可叠加组合；首次打开任一依赖重复分析的开关时才后台分析重复涂装，不筛选零开销 |
| 「重复检测参数」 | 筛选栏右侧的独立按钮：4 个常用模板一键填表 + 六个维度自由组合判定条件（见功能列表），再次打开自动回填上次设置，「恢复默认」回到出厂条件（同车型 + 图片距离 ≤6）；确定即用缓存特征重算，仅本次运行有效 |
| 「置顶」 | 窗口浮在游戏上方，随时调用 |
| 「自动刷新」 | 顶栏开关（默认开）：检测到存档目录变化（新下载/删除涂装）后自动增量刷新——新卡插入式进入卡片墙，选中项与滚动位置保持不变；关闭后回到纯手动，「刷新」按钮语义不变 |
| 「自动定位到游戏」 | 立即把游戏窗口切到前台并发送方向键，跳到选中涂装（游戏未运行则提示）；发送中再点按钮或按 Esc 取消。前提：「我的设计」刚打开（焦点在 1行1列）且未开游戏内筛选 |
| 「设置」 | 调整自动定位的按键节奏（按下保持 + 键间间隔，毫秒），仅本次运行有效（不写文件/注册表，保持单文件零外部依赖）。实测周期阈值约 30ms，低于它会吞键；默认 15+25=40ms，低帧率机器可加大 |
| 「⚠ 检测喷涂状态」 | 弹出已喷涂内存检测的原理与风险确认框；确认后开始检测，完成即自动用喷漆角标标出已上车涂装并弹「已标记喷涂」（角标当次会话内常显，无需开关；游戏未运行则提示先启动游戏）。「仅显示已喷涂(在车上)」「仅显示未喷涂(不在车上)」两个筛选开关在本会话未扫描过时打开也弹同款确认框（与 ⚠ 按钮相同），取消则开关回退无效，已扫描过后直接生效不再弹 |
| 「车厂」 | 按车厂过滤 |
| 「备份整个存档」 | 存档目录打包 zip 到 `backups\` |
| 「所在文件夹」 | 在资源管理器中定位该涂装 |

卡片三行信息：涂装名 / 车型名（可换行完整显示）/ 作者。车型未识别时第三行显示 `ID xxxx + 日期`。卡片缩略图区右上角角标为游戏内位置（`N行M列`，「我的涂装」按车型分组、每列 2 个）；点「⚠ 检测喷涂状态」确认检测后，已上车涂装卡片左上角另贴喷漆罐角标（当次会话内常显，无需开关，切换存档后消失），两者一左一右共存。

## 存档格式说明

工具对存档**只读**。以下格式结论来自本机真实存档验证与社区逆向：

- **Steam 版**：`<Steam>\userdata\<用户ID>\<appid>\remote\`（FH6 appid `2483190`），每个涂装是一组同名分片文件：`Livery_<车型ID>_<- 时间戳>.header / .C_livery / .bigThumb.png …`
- **商店/Xbox 版（pgs）**：`<盘符>:\XboxGames\GameSave\pgs\u_<ID>\<快照号>\ContainersRoot\`，每个涂装是一个同名文件夹（`header` / `C_livery` / `bigThumb.webp`）。`current` junction 指向活跃快照，快照号会滚动（100→101…），工具已自动跟随
- `header` 为二进制元数据（版本/名称/作者/日期/图层数/车型 ID），布局见 `fh6save.py` 注释
- 文件名时间戳为 UTC，界面显示已转为本地时区

## 项目结构

```
├── app.py      # GUI 主程序（只读查看器）
├── fh6save.py  # 存档扫描/header 解析库，可独立运行自检：python fh6save.py
├── gamemem.py  # 游戏进程内存只读扫描器（已喷涂检测 / 读取车辆串表）
├── i18n.py     # 界面多语言（中文源串即 key；FH6_LANG 环境变量 → exe 文件名后缀 → 默认简中）
├── lang_en.py / lang_ja.py / lang_ko.py / lang_zhtw.py  # 四语言译文表（各 183 条）
├── check_i18n.py  # i18n 覆盖校验（改 UI 字符串后必跑，发布前要求 COVERAGE OK）
├── cars.json   # 车型 ID → 名称对照表（打包时内嵌进 exe，运行时只读）
└── LICENSE     # AGPL-3.0
```

## 上游项目

本项目的存档 header 解析逻辑基于上游项目 **[Arstz/FH6_livery_unlocker](https://github.com/Arstz/FH6_livery_unlocker)**
的逆向成果，并用本机 FH4/FH5/FH6 真实存档做了校正（FH6 header v7 的图层数/车型 ID 偏移为本项目补充）。
遵照上游，本项目同样以 **AGPL-3.0** 开源。

车型 ID 对照表最初来自 [HDR 的 FH6 Car Ordinals](https://gist.github.com/HDR/0659d1717bc61504bf83750628963f4f)，现已与游戏内 `Data_Car.str` 字符串表逐条对齐（660 辆）。
