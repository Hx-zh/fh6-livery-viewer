# FH6 涂装查看器 (FH6 Livery Viewer)

**[English](README_en.md) | 中文**

在游戏外浏览《极限竞速：地平线 6》本地存档中的涂装：缩略图平铺、显示**具体车型**与**作者**、可缩放的大图预览。解决游戏内涂装管理界面看不到车型、无法预览纹饰的问题。

**只读工具 —— 不会修改任何存档文件。**

## 功能特性

- 🖼️ **缩略图平铺**：直接读取存档自带的 `bigThumb` 预览图，卡片墙展示全部涂装
- 🏎️ **显示具体车型**：内置 660 辆车的 ID 对照表（与游戏数据对齐），不再对着一串数字猜车
- 📍 **游戏内位置**：每个涂装标注它在游戏「我的涂装」里的行列位置（缩略图角标 + 详情），可按游戏内顺序排列，照着就能在游戏里翻到
- 🎯 **自动定位**：详情面板直接给出从 1行1列 出发的最短方向键路径（利用首尾环绕），「自动定位到游戏」按钮一键切到游戏并发送方向键，精准跳到目标涂装
- 📌 **窗口置顶**：一键把窗口浮在游戏上方，玩着游戏随时查涂装、按定位
- 🔄 **重复涂装检测**：感知哈希 + 车型/作者/名称相似度多规则推断，区分四种场景——同车复刻（经典涂装多人复刻）/ 同车微调（v1/v2 版本）/ 跨车型移植 / 无图同名，可按场景组合筛选；分析按需触发，不筛选则零开销
- 🏭 **车厂筛选**：按车厂快速过滤（保时捷、法拉利……）
- 🔍 **可缩放预览**：卡片右键菜单「查看缩略图」（或详情面板「查看大图」/ 双击右侧预览图）打开大图，滚轮缩放（5%–1200%）、拖动平移、原始尺寸/适应窗口
- 📅 **下载日期排序**：按涂装写入存档的时刻排序（新→旧/旧→新），也可按名称/车型/作者/游戏内顺序排序
- 🔎 **搜索**：按涂装名/作者/车型过滤
- 📋 **原生复制**：详情文本可选中复制（Ctrl+C / 右键菜单），卡片右键菜单复制位置/名称/车型/作者
- 💾 **一键备份**：把整个存档目录打成 zip（只读操作）
- 🖥️ **双版本存档支持**：Steam 版（userdata）与商店/Xbox 版（`XboxGames\GameSave\pgs`）自动识别

## 环境要求

- Windows 10/11
- Python 3.10+
- [Pillow](https://pypi.org/project/Pillow/)（`pip install pillow`）——用于解码 FH6 存档的 WebP 预览图；不装也能运行，但涂装缩略图无法显示

## 快速开始

```bash
pip install pillow
python app.py
```

启动后自动定位本机 FH6 存档（Steam 读注册表，商店版扫描 `XboxGames\GameSave\pgs`），也可以用「手动选择目录…」指定 `remote` 或 `ContainersRoot` 目录。

## 打包发布

```bash
python -m PyInstaller FH6LiveryViewer.spec
```

产出为单文件 `dist\FH6LiveryViewer.exe`，`cars.json` 已内嵌（运行时只读，不释放到用户目录）。


## 使用说明

| 操作 | 说明 |
|---|---|
| 单击卡片 | 选中，右侧显示大图与元数据（名称/车型/作者/游戏内位置/按键路径/日期/层数/大小/重复组） |
| 双击卡片 | 自动定位到游戏内该涂装（等同详情面板「自动定位到游戏」按钮） |
| 右键卡片 | 弹出菜单：查看缩略图 / 定位到涂装位置 / 复制游戏内位置、名称、车型、作者 |
| Ctrl+C | 焦点在详情框时复制选中文本；否则复制选中涂装的游戏内位置 |
| 「涂装筛选」 | 全部为独立开关，可叠加组合（多场景为 OR）；首次打开任一开关时才后台分析重复涂装，不筛选零开销 |
| 「置顶」 | 窗口浮在游戏上方，随时调用 |
| 「自动定位到游戏」 | 立即把游戏窗口切到前台并发送方向键，跳到选中涂装（游戏未运行则提示）；发送中再点按钮或按 Esc 取消。前提：「我的设计」刚打开（焦点在 1行1列）且未开游戏内筛选 |
| 「设置」 | 调整自动定位的按键节奏（按下保持 + 键间间隔，毫秒），仅本次运行有效（不写文件/注册表，保持单文件零外部依赖）。实测周期阈值约 30ms，低于它会吞键；默认 15+25=40ms，低帧率机器可加大 |
| 「车厂」 | 按车厂过滤 |
| 「备份整个存档」 | 存档目录打包 zip 到 `backups\` |
| 「所在文件夹」 | 在资源管理器中定位该涂装 |

卡片三行信息：涂装名 / 车型名（可换行完整显示）/ 作者。车型未识别时第三行显示 `ID xxxx + 日期`。缩略图右上角角标为游戏内位置（`N行M列`，「我的涂装」按车型分组、每列 2 个）。

## 存档格式说明

工具对存档**只读**。以下格式结论来自本机真实存档验证与社区逆向：

- **Steam 版**：`<Steam>\userdata\<用户ID>\<appid>\remote\`（FH6 appid `2483190`），每个涂装是一组同名分片文件：`Livery_<车型ID>_<- 时间戳>.header / .C_livery / .bigThumb.png …`
- **商店/Xbox 版（pgs）**：`<盘符>:\XboxGames\GameSave\pgs\u_<ID>\<快照号>\ContainersRoot\`，每个涂装是一个同名文件夹（`header` / `C_livery` / `bigThumb.webp`）。`current` junction 指向活跃快照，快照号会滚动（100→101…），工具已自动跟随
- `header` 为二进制元数据（版本/名称/作者/日期/图层数/车型 ID），布局见 `fh6save.py` 注释
- 文件名时间戳为 UTC，界面显示已转为本地时区

## 项目结构

```
├── app.py      # GUI 主程序（只读查看器）
├── fh6save.py  # 存档扫描/header 解析库，可独立运行自检：python fh6save.py
├── cars.json   # 车型 ID → 名称对照表（打包时内嵌进 exe，运行时只读）
└── LICENSE     # AGPL-3.0
```

## 上游项目

本项目的存档 header 解析逻辑基于上游项目 **[Arstz/FH6_livery_unlocker](https://github.com/Arstz/FH6_livery_unlocker)**
的逆向成果，并用本机 FH4/FH5/FH6 真实存档做了校正（FH6 header v7 的图层数/车型 ID 偏移为本项目补充）。
遵照上游，本项目同样以 **AGPL-3.0** 开源。

车型 ID 对照表最初来自 [HDR 的 FH6 Car Ordinals](https://gist.github.com/HDR/0659d1717bc61504bf83750628963f4f)，现已与游戏内 `Data_Car.str` 字符串表逐条对齐（660 辆）。
